## 🚀 Getting Started

### Prerequisites
- [Git](https://git-scm.com/downloads) installed on your system
- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

#### Clone the Repository
```bash
# HTTPS
git clone https://github.com/AbdooMohamedd/AbdooMohamedd.github.io.git

# SSH
git clone git@github.com:AbdooMohamedd/AbdooMohamedd.github.io.git

# GitHub CLI
gh repo clone AbdooMohamedd/AbdooMohamedd.github.io
```

#### Local Development
```bash
# Navigate to project directory
cd AbdooMohamedd.github.io

# Open in browser
# Option 1: Open index.html directly
# Option 2: Use a local server (recommended)

# Using Python
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server

# Using PHP
php -S localhost:8000

# Then visit: http://localhost:8000
```
